# Revision 2026-11-13.12: scope and migration

This release preserves the registered geometry, typed ports, support checks and
independent display-cut model. It adds conditional drawing plans and stronger
evidence boundaries. It does not train a model, bundle reference art or certify
mechanical function. A successful guide still needs independent artistic review.

## Implemented workflow

- Domain-aware design intent, symmetric candidate comparisons and reproducible seeds.
  Equivalent renaming or camera changes do not count as different layouts.
  Default selection samples the distinct equally suitable planning candidates with
  a reproducible content/seed tie-break. Internal novelty is descriptive unless
  explicitly requested as an objective; maximizing an outlier must not lock every
  short request to one family. CLI runs use a fresh seed when none is supplied.
- The pilot bunker builder materializes central hub, longitudinal spine and branched
  circulation. It constructs real rooms, openings, supported flights and landings.
  Ring and stepped organizations remain unavailable to that builder; they must not
  be silently rendered as another family. Other domains have explicit capability
  scopes and require their own tested materializers for novel complete scenes.
- Typed physical relations, bounded support/contact evidence, access sweep checks
  and one result per declared functional contract. Critical unknowns fail strict
  acceptance; an unsupported adapter is not a pass.
- Explicit visual, context, detail, light/material and actor plans, normalized guide
  readability and annotation evidence. Material expression follows local surfaces;
  graphical light treatment is not a physically based shadow simulation.
  The camera search fits occupied subject bounds separately from scenery and checks
  both preview and native guide gates. A large mountain does not justify tiny rooms.
- Bound finish handoff, image-specific visual observations and at most two targeted
  corrections. PNG identity and coverage are checked; visual truth is inspected by
  the reviewer, not asserted by a hash.
- Portable run manifests, numbered outputs and a containment/hash-checked cleanup
  plan that never deletes files itself.
- Manifest version 2 validates observed input identities and binds reviewed PNGs,
  tool facts and source-native pixels when supplied. Empty or forged records fail;
  unreported parameters cannot establish execution parity between clients.
- Reusable furnished-room kits for control, dormitory, storage, workshop, utilities
  and medical spaces. Three secondary arrangements per program add compound
  furnishings, front divisions, work surfaces and supported storage; every new
  fixture participates in support and access validation. These are explicit kits
  for sufficiently large rooms, not a universal furnishing solver.
- Registered triangle material coordinates retain marks across prescribed corners
  and rebuilt deformations, with style-seed changes isolated from depth/ownership.
  [Seated and leaning actor templates](actor-poses.md) add actual pelvis/seat,
  foot/floor and hand/tool contacts without asserting biomechanics.
- [Sixteen executable evaluation questions](../evals/executable-cases.md) separate
  rule, geometry, guide and final-pixel evidence. Thirteen recipe examples carry
  verified decision contracts and reproducible positive/negative commands.

## Compatibility

Physical `schema_version: 2` and `workflow_version: 3` are separate concepts.
The workflow version opts into the new visual/evidence requirements. Preserve the
old fixtures as explicitly partial educational API examples. To migrate a scene,
add the required plans and mapped requirement witnesses, revalidate the complete
physical model, render a new bound view and freeze a new lock. Do not merely change
the version number or copy another scene's witnesses.

Old locks cannot authorize modifications to new scenes or generated images. Editing
scene, view or image requires new corresponding evidence. A noncritical unmodeled
detail may be reported as limited; a critical missing adapter blocks that claim.

Nature supplies useful principles for mass, silhouette, overlap and local marks.
Procedural vegetation is contextual geometry, not botanical identification.
Seated/leaning task templates are supported within their declared fit limits;
anatomical or biomechanical accuracy, arbitrary animal structures, fish-eye
projection, structural loads and mechanism simulation remain outside that scope.

## Distribution check

Run both unittest suites, example validation and package audit. Build a ZIP from
only original text/source files, compare every extracted file hash with the staged
source, then run checks from a different working directory. The runtime must not
refer to a developer's image collection, machine paths or prior conversations.
Final-image reports belong in project output or run diagnostics, never the package.
`scripts/build_package.py --out <new release.zip>` audits sources and verifies each
ZIP entry against its source hash, recording an external manifest beside the ZIP.
