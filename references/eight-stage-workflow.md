# Eight stages with proportionate evidence

The default stages and decisions are defined in [SKILL.md](../SKILL.md). They order design work; they do not require a complete CAD implementation of every subject.

| Stage | Default evidence | Scope example |
|---|---|---|
| Site/operation | setting and functional intent | tunnel continuation, not an unseen external portal |
| Program | spaces and relationships | passage between banks of pipes |
| Massing | chosen arrangement and alternative | asymmetric banks with axial depth |
| Structure | support intent and available checks | wall brackets, floor support, unverified rock loads |
| Levels/openings | circulation and clearance | one unobstructed walking envelope |
| Systems | connections, boundaries and detail map | continuous runs, capped branches, hangers |
| Representation | spatial plan and optional inspected guide | consistent projection, foreground/mid/background |
| Finish/review | actual PNG and named observations | inspect connections independently of the guide |

`illustration_workflow.prepare` saves all eight decisions. They are explicitly labeled planned/not_applicable, never automatic physical approvals. Numerical coverage is a separate recomputed record. For explicitly requested strict occupied-building validation, use [architectural gates](architectural-gates.md); its approval chain remains intact.
