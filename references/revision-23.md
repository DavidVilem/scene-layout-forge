# Revision 2026-11-17.23

- The regular workflow again delivers ilustrada.png and coloreada.png. An explicit 3D request activates a separate reconstruction kernel; ambient video remains independent and off by default.
- A source image can be the existing colored pair or a single external raster image. The kernel retains source identity and never substitutes an unrelated technical fixture.
- Agent-authored visual specifications compile through general composed shapes and registered indexed meshes. Missing domain-specific templates do not require abandoning construction. Visual evidence and hidden assumptions remain distinct.
- Existing scene/route validators stay in place. Additional checks cover named anchors on actual surfaces, coincident contacts, visual correspondence inventory, invalid meshes and inferred-geometry disclosure.
- The viewer retains source reference buttons, actual 3D orbit, assembly separation, clipping and schematic projections. Models use optional semantic colors without changing source pixels.
- Tests cover multiple geometry families, malformed meshes, false surface contacts, gaps, route endpoint failures, source retention and standalone reconstruction acceptance. Browser tests also load source-image references and support scenes without pipe connections.

This release does not bundle learned single-view reconstruction, automatic segmentation, hidden-surface recovery, articulation or engineering simulation. The executing agent creates and checks the specification from source evidence. Quality of an arbitrary unseen subject still requires actual image/model review; a conceptual model may be less detailed than the raster artwork. For unconstrained or ambiguous images state partial scope rather than claiming exact full conversion.
