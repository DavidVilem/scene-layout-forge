# Revision 12: sixteen executable scoped evaluation cases

Sixteen original balanced evaluation cases with explicit rule/geometry/guide/finished-pixel boundaries. This catalogue is not sixteen generators or sixteen generated illustrations.

Thirteen recipe-based examples coexist with sixteen executable bounded evaluation questions. A validated component fixture never implies a complete unsupported subject materializer. Legacy coverage remains explicit.

The final consolidated suite owns release execution results. The case registry executes rule, geometry and calculated-guide checks; it does not call an image model. Actual finished-pixel review remains a separate, image-bound operation.
