# Default-route regression matrix

Run the tunnel, observatory, skyline and winch briefs in examples/worked-cases/general-illustration.md in fresh sessions. Record separately: completion (actual PNG), history completeness, applicable numerical failures, unsupported checks, pixel coherence, detail by zone, optional annotations, and fidelity to the requested view. An agent cannot pass by only generating planning files or by reporting a guide as the final illustration.

Negative probes: change a typed connection endpoint; remove a required bearing; corrupt a recorded guide; omit a relationship from pixel review; change reviewed pixels; request a third local correction. They must be rejected in the relevant check. A native shape with an unsupported contact adapter must remain explicitly limited while permitting default illustration. Explicit strict-mode requests must still reject unsupported critical checks.

Unit tests verify evidence/control flow, not image quality. This matrix is an agent evaluation procedure; never report all cases as visually passed without running image generation and inspection for each.


Continuity probes: unknown endpoint; a cap shared by two pipes; a crossing claimed as joined without a tee; an occlusion used as a terminal; a wall passage without continuation; a coordinate endpoint detached from its destination; an unrecorded added route. These must fail contract checks when explicit contradictions exist. A descriptive-only route contract must still permit illustration. The actual PNG must separately show natural terminations and attached branches without losing density, neutral paper, line hierarchy or freedom of view. Keep uncertainty for genuinely hidden/subpixel joints. No load, pressure or flow tests are required for these visual tasks.
