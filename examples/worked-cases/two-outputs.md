# One design, two outputs

Short prompt: "Use $scene-layout-forge to illustrate a mountain cable-car station."

Produce and review the subject in graphite as ilustrada.png. Then edit those pixels with the available image tool: muted stone/concrete, cool steel, warm wood where present, restrained vegetation and soft mountain daylight. Do not add wood panels merely to use a color. Preserve cable routes, boarding openings, counts and annotations. Review the pair and deliver coloreada.png in the same numbered folder. Keep all intermediate files in history.

Override: "Only the graphite version" produces only ilustrada.png. "Use muted blue and copper accents for the colored version" changes the palette, not the scene geometry. Old files named final.png are historical artifacts and are not renamed automatically.

Failure case: the color tool moves a cable endpoint, changes a stair or rewrites a label. Record changed, request a local correction, and compare again. Missing editing capability means a partial delivery with explicit status, not a duplicate monochrome file called coloreada.png.
