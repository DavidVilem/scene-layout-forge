# Worked case: label beside a rail and an operator

Brief: label a reducer in a dense maintenance platform. First identify a visible reducer face that is not occupied by the inspector's hand or the guardrail silhouette. Place a short hand-lettered caption in available space and use a fine elbow leader with a small tip on that face. If no visible face exists, revise the guide's camera or allowed layout rather than pointing into an occluded area.

Reject a tip on the rail, a line crossing the person's head, a caption underlined like a report heading, or a tip touching a different nearby bearing. Check the actual pixels at native size; the guide's part ID is not final-image evidence. If one label fails, correct that annotation while preserving all other labels, quantities and view. This consumes the normal correction budget.

Use the same approach for architecture, ducts or mechanical sections; do not copy these objects into unrelated requests. This worked case has no image assets and is not an executable example.
