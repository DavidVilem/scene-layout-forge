# Procedural presentation example

Run `python -B build.py` to emit the botanical pavilion specification as JSON. Save it in an execution history outside the skill. It demonstrates real door openings, framed glazing, roof ribs and seams, roof services, planted beds, circulation and host-owned parts.

The example contains no input artwork. Use an independently generated or user-provided source image for reconstruction testing; adapt the specification to its actual visible design. Do not claim the procedural example is an image-to-3D inference engine.

Short test: "Use $scene-layout-forge to illustrate a botanical research pavilion and create its detailed presentation-maquette explorer. Preserve the entrance, glazing, planting and roof services, and keep history."

Review the real image and HTML together. The geometry tests establish internal checks only.
